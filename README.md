# AI 模型评测平台

一个本地运行的 **多模型横向评测平台**：通过 OpenAI 兼容协议接入任意大模型，自动化完成六大能力维度的测试，并生成可视化数据报表，直观对比模型间的差距与进步。

## 功能特性

- **模型接入**：只需「模型调用名称 + API Key」即可添加，支持自定义 Base URL（DeepSeek、通义千问、智谱、Kimi 等所有 OpenAI 协议服务）；**默认关闭思考模式**（调用时发送关闭思考参数，遇到不支持的供应商自动降级重试）
- **五档难度体系**：简单 / 中等 / 中高 / 高难 / 极难，每个维度均覆盖全部难度档。题库页可按难度切换浏览（题目数实时联动），发起评测时可筛选指定难度；自定义题目支持选择难度。前端三道实测题归入「中等」
- **六大测试维度**（可自由勾选参与模型与测试项目）：
  | 维度 | 说明 | 评分方式 |
  | --- | --- | --- |
  | 通用常识 | 26 道 MMLU 风格选择题（含图灵测试、汉谟拉比法典、黎曼猜想等进阶题） | 自动判分 |
  | 数学推理 | 15 道 GSM8K 风格应用题（含浓度混合、复利、蓄水池、工程合作等） | 数值自动校验 |
  | 逻辑推理 | 15 道逻辑题（含三盒标签、十二球称重、骑士骗子升级版等） | 自动判分 |
  | 编程能力 | 16 道（Python 算法 + 前端页面生成，含合并区间/接雨水/编辑距离/N 皇后等经典题） | 沙箱执行 + 无头浏览器实测 + 裁判点评 |
  | 情感能力 | 15 道（共情选择 + 开放情境，含客户投诉、团队冲突、委婉提醒等复杂场景） | 客观 + 裁判模型打分 |
  | 多模态能力 | 15 道图片理解题（名画/动物/地标/信号灯） | 自动判分 / 裁判打分 |

- **题目详情**：题库中点击任意题目即可查看题干、图片、选项、标准答案（客观题）或评分标准与示例答案（主观题）
- **答案预览**：评测明细中，编程题可一键“运行结果”（重新执行模型代码，逐用例展示输入/期望/实际输出）；前端题可一键“页面预览”（在沙箱 iframe 中交互体验模型生成的页面）

  前端代码实测题（真实浏览器运行验证）：
  1. **互动拍立得相机**：相机外壳/镜头/快门/相纸出口空间关系、点击快门吐出相纸、光影克制
  2. **macOS 风格网页操作系统**：八合一（文本编辑器、终端、Python 环境、代码编辑器、游戏、文件管理器、绘图、视频编辑），Dock 点击开窗、窗口拖动关闭
  3. **科幻飞船驾驶舱 HUD**：准星/仪表/星空三层差异化响应速度制造纵深感、玻璃反射
- **可视化报表**：排行榜（含总耗时、平均耗时、输出速度）、能力雷达图、各维度对比柱状图、模型差距热力矩阵、跨轮次进步趋势、多轮对比表
- **性能指标**：逐题记录接口延迟与输出 token 数，自动统计每个模型的总耗时、平均耗时与输出速度（tokens/秒）
- **数据持久化**：SQLite 本地存储，所有历史评测可追溯

## 快速开始

### 1. 启动后端（首次自动安装依赖）

```bat
cd backend
python -m venv .venv
.venv\Scripts\pip install -r requirements.txt
.venv\Scripts\python -m uvicorn app.main:app --host 127.0.0.1 --port 8000
```

也可以直接双击 `start.bat`（自动安装依赖并启动，浏览器打开 http://127.0.0.1:8000）。

### 2. 使用

1. **模型管理**：添加模型（名称 + 模型调用名 + Base URL + API Key），点「测试连接」验证
2. **发起评测**：勾选参与模型与测试项目，可指定裁判模型（主观题自动评分用），开始评测
3. **评测总览 / 数据报表**：查看排行榜、雷达图、差距矩阵与进步趋势

## 技术架构

- **后端**：Python + FastAPI + SQLite + openai SDK
- **前端**：Vue 3 + Element Plus + ECharts（生产构建后由后端直接托管，单端口访问）
- **评测引擎**：异步并发调度（4 并发/轮）、超时与错误隔离、逐题入库、进度实时可见
- **评分体系**：
  - 客观题：选项匹配 / 数值容差校验 / 文本包含（含否定识别）
  - Python 算法题：提取代码块 → 临时沙箱执行 → 隐藏测试用例比对
  - 前端页面题：提取 HTML → Playwright 无头 Chromium 实测（元素存在/点击交互/指针响应/控制台报错，占 60%）+ 裁判模型点评视觉表现（占 40%，未配置裁判时按实测比例折算）
  - 主观题：裁判模型按评分标准输出 JSON 打分（1-10 分）
- **数据持久化**：SQLite 本地存储；启动时对题库 JSON 做**增量迁移**（按题目全文去重，并同步难度标注），网页里自定义添加的题目与已配置模型全部保留

## 开发说明

- 前端开发模式：`cd frontend && npm install && npm run dev`（代理 `/api` 到 8000 端口）
- 前端生产构建：`npm run build`，后端自动托管 `frontend/dist`
- 前端实测依赖：`pip install playwright && playwright install chromium`（start.bat 会自动安装）
- 自检工具（无需真实 API Key）：
  - `python test_scorers.py` —— 离线验证评分引擎
  - `python mock_openai_server.py` —— 启动本地模拟 OpenAI 服务（端口 8001，返回满分答案），可添加模型 `mock-chat` / `http://127.0.0.1:8001/v1` 做全链路自检（含前端题浏览器实测）

## 安全提示

- API Key 明文存储于本地 SQLite（`backend/app/data/app.db`），请勿将数据库文件外传
- 评测会真实调用所选模型的 API 并产生费用，请留意用量
- Python 代码与前端页面会在本机临时环境执行（子进程 + 无头 Chromium，均有超时限制，无网络隔离），建议仅在可信环境使用
